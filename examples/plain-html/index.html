ZERO BUILD STEP

One script tag.
A real helper.

This page has no React app and no bundler. It loads the embed build from the local package, auto-mounts the widget, and talks to a tiny Node route.

<script data-endpoint="/api/chat">

What is inside?

The IIFE bundle includes React, the Shadow DOM UI, safe Markdown, streaming, abort, and localStorage persistence. Nothing else is required.

  1. Script reads its data attributes.
  2. Widget auto-mounts after DOM ready.
  3. POSTs SSE requests to your endpoint.
